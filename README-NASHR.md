3. **احتفظ أيضاً بالنسخة الجديدة (ZIP) في مجلد منفصل** قبل فكّ الضغط.

## الخطوة 3 — تفعيل الدخول بالبريد (مرة واحدة فقط)
1. افتح: https://console.firebase.google.com ← مشروع **prof-kerdjidj**
2. من القائمة اليسرى: **Authentication**
3. تبويب **Sign-in method** ← **Add new provider** ← **Email/Password**
4. فعّل **Enable** ثم **Save**.
5. في نفس الصفحة، أسفل: **Authorized domains** — تأكد من وجود:
   - `prof-kerdjidj.web.app`
   - `prof-kerdjidj.firebaseapp.com`
   - `localhost` (للتجربة على حاسوبك — اختياري)

> بدون هذه الخطوة سيظهر للتلميذ: «طريقة الدخول غير مُفعّلة في Firebase».

## الخطوة 4 — النشر (نافذة الأوامر)
1. اضغط زر **Windows** واكتب: `cmd` ← اضغط **Enter**.
2. اكتب الأمر التالي (غيّر المسار إن كان مجلدك في مكان آخر) ثم **Enter**:
   ```cmd
   cd "%USERPROFILE%\Desktop\prof-kerdjidj"
   ```
3. الآن انقر مرتين على الملف **`deploy.bat`** داخل المجلد — أو اكتب في النافذة:
   ```cmd
   deploy.bat
   ```
4. اتبع ما يطلبه منك (يفتح المتصفح لتسجيل دخول Google بحساب الأستاذة، ثم ينشر تلقائياً).

**الأوامر التي تُنفَّذ داخلياً (للمعلومة فقط):**
```cmd
npm install -g firebase-tools
firebase login
firebase deploy --only firestore:rules,firestore:indexes
firebase deploy --only hosting
```

**النتيجة المتوقعة:** سطر أخير فيه ✅ ورسالة:
```
Hosting URL: https://prof-kerdjidj.web.app
```

## الخطوة 5 — التحقق بعد النشر (قائمة عربي)
افتح الموقع في **الهاتف والحاسوب** وتأكد:

| ✓ | الاختبار | النتيجة المتوقعة |
|---|---|---|
| ☐ | افتح `https://prof-kerdjidj.web.app` | الصفحة تفتح، والدروس التي نشرتها تظهر للجميع |
| ☐ | عنوان الصفحة والتذييل | الاسم مكتوب **«الأستاذة قرجيج»** (بالقاف) في كل الصفحات |
| ☐ | صفحة **المواقيت** كزائر | تظهر الحصص العامة، و**لا تظهر** الحصص الخاصة (VIP) |
| ☐ | `admin/index.html` كزائر | **لا يظهر أي قسم** — شاشة دخول الأستاذة فقط |
| ☐ | سجّل دخول الأستاذة (Google) | تظهر كل الأقسام (نظرة عامة، الدروس، التلاميذ…) |
| ☐ | أنشئ إعلاناً من **الإدارة ← الإعلانات** | رسالة «تم النشر ✓» ثم يظهر الإعلان في فضاء التلاميذ |
| ☐ | أنشئ درساً من **الإدارة ← الدروس** | يظهر الدرس في صفحة «الدروس» للجمهور |
| ☐ | أضف تلميذاً من **الإدارة ← التلاميذ** | يظهر في الجدول فوراً |
| ☐ | سجّل خروجاً ثم ادخل كتلميذ (بريد ورقم سري جديد) | تظهر استمارة: **الاسم + السنة + الاهتمام** ثم يدخل لفضائه |
| ☐ | التلميذ: أنجز تمريناً | تصحيح فوري + XP يزيد في «تطوّري» |
| ☐ | الأستاذة: **الإدارة ← التلاميذ** | ترى XP التلميذ الذي أنجز التمرين (وتستطيع ربطه ببطاقته) |
| ☐ | أرسل رسالة من صفحة «تواصل» كزائر | تظهر رسالة «أُرسلت رسالتك ✓» وتصل إلى **الإدارة ← الرسائل** |
| ☐ | أضف حصة «خاصة VIP» وحدّد تلميذاً | لا تظهر لبقية التلاميذ ولا للزوار، وتظهر للتلميذ المختار فقط |
| ☐ | **الهاتف:** افتح الصفحات | لا تمرير أفقي، الأزرار مريحة، لا تكبير تلقائي عند الكتابة |
| ☐ | **الهاتف:** افتح `responsive-check.html` واضغط «ابدأ الفحص» | كل الصفحات «سليم ✓» |
| ☐ | **F12 ← Console** على الحاسوب | لا أخطاء حمراء (رسائل بيضاء/صفراء عادية مسموحة) |
| ☐ | بدّل اللغة AR ⇄ FR | كل النصوص والاتجاه يتغيّران في كل الصفحات |

> 📸 إن ظهر أي خطأ أحمر في Console: صوّر الشاشة وأرسلها لي — سأحدد السطر بالضبط.
