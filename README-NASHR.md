قبل أي شيء، خذي نسخة احتياطية. هذه ثلاث خطوات فقط:

1. افتحي هذا الرابط في المتصفح: <https://github.com/korichawki5-ai/prof-kerdjidj>
2. اضغطي الزر الأخضر **`Code`** ← **`Download ZIP`** → احفظي الملف على المكتب أو في قرص خارجي.
   **هذا الملف هو نسختك الاحتياطية من الكود.** لا تحذفيه.
3. **البيانات (Firestore):** هذه النسخة الجديدة **لا تحذف ولا تغيّر أي سطر من بياناتك الحالية**،
   وكل تعديلات قواعد الأمان فيها **تسمح أكثر ولا تمنع أكثر**. ومع ذلك، إن أردتِ نسخة من البيانات:
   Firebase Console ← **Firestore Database** ← قائمة **⋮** ← إن ظهر خيار **Import/Export** استعمليه،
   وإن لم يظهر عندك فلا مشكلة — لن تُفقد أي بيانات، والدليل أن الترقية **إضافية فقط**
   (مجموعة جديدة اسمها `studentLinks` + صلاحيات أوسع).

## ② الطريقة الأسهل: النشر من مجلد الـ ZIP (موصى بها)

### الخطوة 1 — فكّي ضغط الملف
- انقري بالزر الأيمن على `prof-kerdjidj-2026-10-02.zip` ← **Extract All…** ← **Extract**.
- ستحصلين على مجلد اسمه **`prof-kerdjidj`**.

### الخطوة 2 — شغّلي سكربت النشر
- ادخلي إلى المجلد، وانقري **نقرة مزدوجة** على الملف: **`deploy.bat`**
- ستفتح نافذة سوداء. **اتركيها تعمل** ولا تغلقيها. سيظهر:

| على الشاشة | المعنى |
|---|---|
| `══ 1/6 · التحقق من Node.js ══` ثم `v20.x` | كل شيء جيد |
| `══ 2/6 · تثبيت Firebase CLI ══` | يثبّت الأداة مرة واحدة فقط (قد تأخذ دقيقتين) |
| `══ 3/6 · التحقق من مفاتيح Firebase ══` ثم `[OK] المفاتيح موجودة` | المفاتيح سليمة |
| `══ 4/6 · تسجيل الدخول ══` | سيفتح المتصفح → اختاري **حساب الأستاذة** → **السماح/Allow** |
| `══ 5/6 · ربط المشروع + رفع القواعد ══` | يسألك: `Which project…` → **اختاري `prof-kerdjidj`** بالأسهم ثم Enter. ثم يسألك عن alias اكتبي `default` ثم Enter |
| `══ 6/6 · نشر الموقع ══` ثم `[OK] تم النشر 🎉` | **انتهى!** الموقع صار نسخة جديدة |

> إن ظهر `Firebase CLI` قديم جداً أو رسالة خطأ في الخطوة 2، اكتبي في نافذة سوداء:
> `npm install -g firebase-tools` ثم أعيدي تشغيل `deploy.bat`.

> 💡 لا يهمّ إن ظهر في سطر الأوامر اسم `storage` ثم تجاهله النظام — لا مشكلة، هو غير مستعمل في الموقع.

### الطريقة البديلة (4 أوامر يدوياً)
في نافذة سوداء **داخل مجلد المشروع** اكتبي سطراً سطراً:

```bat
npm install -g firebase-tools
firebase login
firebase use prof-kerdjidj
firebase deploy
```

آخر أمر هو الأهم: **`firebase deploy`** وحده يكفي — يقرأ الإعدادات من `firebase.json` ويرفع
الموقع + القواعد + الفهارس في عملية واحدة.

## ④ خطوة إلزامية (إن لم تكوني فعلتِها سابقاً): صلاحية الأستاذة

بدون هذه الخطوة تفتح لوحة الإدارة لكن **لن تُقبل أي كتابة**.

1. <https://console.firebase.google.com> ← مشروع `prof-kerdjidj`
2. **Authentication → Users** ← افتحي حساب الأستاذة ← انسخي الـ **UID**
3. **Firestore Database** ← مجموعة `users` ← افتحي مستنداً بمعرّف = الـ UID
   (إن لم يوجد: **Add document** ← الصقي الـ UID في خانة *Document ID*)
4. أضيفي الحقل: `role` من نوع **string** وقيمته **`admin`** ← **Update**

## ⑥ إذا ظهرت مشكلة

| ما يظهر | السبب | الحل |
|---|---|---|
| `Error: Failed to authenticate` | لم يتم الدخول | `firebase login` ثم أعدي `firebase deploy` |
| `Missing permissions` / `permission-denied` في لوحة الإدارة | `role = "admin"` غير موجود في `users/{uid}` | راجعي القسم ④ |
| «المفاتيح موجودة» لا تظهر، ورسالة `COLLEZ_ICI` | مفاتيح Firebase لم تُلصق | راجعي `SETUP-AR.md` الجزء 3 |
| نافذة Google تُفتح وتُغلق بسرعة على الهاتف | النوافذ المنبثقة محجوبة | تم إصلاحه: الكود يتحوّل تلقائياً إلى الدخول بصفحة كاملة. أعدي المحاولة |
| الموقع يظهر قديماً بعد النشر | ذاكرة المتصفح (Cache) | **Ctrl + F5** على الحاسوب؛ وعلى الهاتف: إعدادات Chrome ← الخصوصية ← محو بيانات التصفّح |
| تلميذ يرى «بانتظار تأكيد الأستاذة» | هذا هو الوضع الصحيح | من الإدارة: «طلبات في الانتظار» ← «ربط ببطاقة» |
| `Error: Cannot understand what targets… storage` | يُستعمل أمر يذكر `storage` وحده | استعملي `firebase deploy` بلا تحديد أهداف (لا Storage في هذا المشروع) |
