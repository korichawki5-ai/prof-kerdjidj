# اختبارات المنصّة · Tests

## التشغيل
```bash
cd tests
npm install          # مرة واحدة فقط (يثبّت jsdom)

# في نافذة طرفية أخرى: شغّل خادماً محلياً على المنفذ 4322
python3 -m http.server 4322 --bind 0.0.0.0 --directory ..

# ثم:
node run-all.mjs
```

## ماذا يفحص؟
| القسم | المحتوى |

| **2** | محرّك التمارين: تصحيح فوري، تمييز الخطأ والصواب، الشرح، حساب XP، شاشة النتيجة، مراجعة الأسئلة الثمانية |
| **3** | لوحة الإدارة: وحداتها العشر + إضافة/تكرار/حذف سؤال في بانوراما الاختبار |
| **4** | الإعدادات: تعديل معلومات التواصل → حفظ → **التحقق من ظهورها في صفحة «تواصل» في جلسة جديدة** + سريان ضبط XP على المحرّك |
